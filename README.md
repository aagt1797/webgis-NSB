# Noah Sukses Bersama WebGIS

Project peta statis sederhana yang menggunakan Leaflet untuk menampilkan lokasi kantor dan cabang.

## Cara menjalankan

1. Buka folder project.
2. Jalankan server statis dari terminal:

```bash
python -m http.server 8000
```

3. Buka browser ke:

```text
http://localhost:8000
```

## Files

- `index.html` : halaman utama
- `style.css` : styling layout
- `script.js` : inisialisasi peta dan marker

## Catatan

Proyek ini dibuat sebagai starter awal untuk aplikasi web GIS berbasis Leaflet.
